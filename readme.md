# Description:
This repository is a demo complying with the points in requirements.md, with an architecture design that favors scalability and modularity for different hardware setups.

It is being layered into:
- Core layer - Code mostly generated by STM32CubeMX, initializes power, clock and peripherals and has a MUX selector to load a specific application based on a macro defined in config.h.
- Application layer - Defined at compile time with a MACRO at config/config.h, initializes and/or calls the appropiate services/ and/or third_party/ in such a way that the logic is tailor made for specific purposes.
- Services layer - Logic that glues low level drivers to achieve a specific type of task.
- Drivers - HAL or low level drivers offered by STM32 environment.
- Third_party - Other repositories added as git submodules, often used in the same layer as the drivers (so being accessible by either application or services layers)

# Installation:
To initialize the git submodules:
- git submodule init
- git submodule update --recursive
- Open .project files with STM32CubeIDE / import the root folder from it that has the project.
- Opening the .ioc file from STM32CubeMX is possible to modify the pin peripherals, as long as the labels are consistent to not break any service.
